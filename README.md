# PsiCrawler

PsiCrawler 是一个计划中的网络爬虫项目，用于收集互联网上公开可访问的计算实验数据、基准测试结果、论文页面和相关文章元数据。

## 项目目标

- 爬取公开的计算实验数据集与数据仓库链接
- 收集论文、技术文章、实验报告等公开网页的基础元数据
- 保存数据来源、抓取时间、页面链接等可追溯信息
- 为后续的数据清洗、检索、分析和知识库构建提供原始材料

## 设计原则

- 只处理公开可访问的数据
- 尊重目标网站的 `robots.txt` 和访问规则
- 对请求频率进行限制，避免给公开服务造成压力
- 记录每条数据的来源，保证结果可审计、可复查
- 不绕过登录、付费墙、验证码或其他访问控制机制

## 计划功能

- 支持配置多个公开数据源
- 支持文章页面与数据集页面的分类抓取
- 提取标题、链接、摘要、发布时间、作者、数据集地址等字段
- 输出结构化结果，便于后续导入数据库或搜索系统
- 提供日志与错误记录，方便长期运行和排查问题

## 适用场景

- 计算实验数据收集
- 公开论文与技术文章索引
- 数据集发现与整理
- 学术知识库或实验数据库的前期素材采集

## 合规说明

PsiCrawler 仅面向公开网页和公开数据资源。使用者应遵守目标网站的服务条款、版权政策、数据使用协议和当地法律法规。
